# 狗头军师悬浮面板：意图判断与候选回复排序

用户于 2026-09-22 确认的方案。参考用户提供的 Jev 蓝白半透明回复面板，以现有 Mac AppKit 集成实现；不新增独立网页或迁移 Android 工程。

## 布局

420 × 640 pt，可拖动悬浮球、面板置顶和半透明白色圆角外壳。标题“狗头军师”，右侧设置与收起。次行是当前对象、阶段、目标，并提供打开设置的对象按钮。

主滚动区依次为：

1. 对方可能的意图：仅为基于可见聊天的推测，证据不足时明确说明。
2. 一句原文依据。
3. 军师建议：七种主策略之一与本轮行动建议。
4. 候选回复排序及说明按钮。
5. 一至三张候选卡片，首张浅蓝、其他浅灰，展示排名、百分比、大字原文、复制和填入；理由与代价默认折叠。

底部固定“重新分析／读取对话”“更像我一点”“详细分析”及状态行。详细分析保留事实、其他推测、未知、Jev 策略置信度、下一步和停止条件。设置复用对象档案、目标、回复偏好、接口、OCR、透明度和记忆管理。

## 评分

Jev 选择策略 → 同一回复模型生成分析及候选 → 同一回复模型独立评估候选（至少两条时）。评分输入包括原文、当前对象背景、场景、策略和口吻偏好；候选只提供 id 与原文，减少生成理由和原排名对评分的影响。

逐候选 0–100 相对推荐分由模型给出，本地校验完整且唯一的 id、有限分数、范围及非零总分；按分数排序，最大余数法归一化到合计 100% 的整数权重。分数不做成功率或准确率解释。

只有一条时 100% 表示唯一候选；零条时不评分、不强凑回复。评分请求或格式失败时保留草稿，明确标注排序暂不可用，不显示百分比。模型返回全零也视为不可排序，不均分伪装成功。

## 改写与状态

“更像我一点”沿用已核对的对话和本轮分析，只采纳新输出的候选；保留原事实、意图、策略和停止条件。策略变更、空候选或长度越界时保留原结果；成功后重新评分。期间禁用候选操作。输入或对象变化时用版本校验丢弃迟到结果。

已开启本地轮询时，新消息被读取后移除旧候选并提示重新核对；不声称未读屏时能感知外部消息。填入仍重新核对当前窗口和对话，只放入草稿，不发送。

## 验证

54 项离线测试通过，新增评分 id／数值／归一化／排序对应关系、失败降级、请求顺序和改写保留分析的检查。

视觉与原生交互检查状态另见仓库根目录 design-qa.md；离线演示权重是明确标识的示例，不能作为真实评分结果。
